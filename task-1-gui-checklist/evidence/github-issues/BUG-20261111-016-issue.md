## Body

### Problem Summary

**What was tested:**  
Cấu trúc thẻ tiêu đề trang cấp độ 1 (h1) trên cả 3 màn hình.

**What happened:**  
Cả 3 trang Login, Register, Forgot Password đều chỉ có thẻ `<h2>` làm tiêu đề, không có bất kỳ thẻ `<h1>` nào.

**Why this is incorrect:**  
Vi phạm FR-21 quy định cấu trúc ngữ nghĩa tiêu đề trang: 'Mỗi trang có đúng 1 thẻ h1 mô tả nội dung trang'.

### Steps to Reproduce

### Actual Result
