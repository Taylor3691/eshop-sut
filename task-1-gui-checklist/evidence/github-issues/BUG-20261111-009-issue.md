## Body

### Problem Summary

**What was tested:**  
Validation độ mạnh mật khẩu khi đăng ký tài khoản.

**What happened:**  
Nhập mật khẩu mạnh đúng chuẩn FR-01 gồm 8 ký tự có chữ hoa, thường, số, ký tự đặc biệt (ví dụ: 'Valid123@') bị hệ thống từ chối với lỗi 'Mật khẩu quá yếu!'.

**Why this is incorrect:**  
Regex trong `Register.jsx` dùng `^(?=.*[a-z])(?=.*[A-Z])(?=.*\d)(?=.*\s)[A-Za-z\d\s]{8,}$` bắt buộc phải có khoảng trắng (`\s`) và cấm ký tự đặc biệt `@`, vi phạm trực tiếp yêu cầu mật khẩu mạnh theo FR-01.
