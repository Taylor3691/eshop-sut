# GitHub Issue: [BUG][Login] Nút Sign In có tabIndex={1} làm sai lệch thứ tự focus phím Tab

- **Bug ID:** BUG-20261111-002
- **Labels:** `type: bug`, `status: new`, `severity: minor`, `priority: P2`, `module: login`

## Body

### Problem Summary

**What was tested:**  
Điều hướng bằng bàn phím (Tab order) trên màn hình Login.

**What happened:**  
Khi bấm Tab lần đầu từ đầu trang, focus lập tức nhảy xuống nút submit 'Sign In' thay vì đi tuần tự từ trên xuống dưới.

**Why this is incorrect:**  
Nút submit bị gán thuộc tính `tabIndex={1}`, vi phạm FR-21 quy định thứ tự focus Tab phải đi từ trên xuống dưới, trái sang phải.

### Steps to Reproduce

1. Tải lại trang `http://localhost:5173/login`.
2. Nhấn phím Tab một lần.
3. Quan sát phần tử nào nhận focus đầu tiên trên giao diện.

### Expected Result

Focus phải đi vào các liên kết trên header trước, sau đó đến trường Email, trường Mật khẩu rồi mới tới nút Đăng nhập.

### Actual Result

Focus nhảy thẳng vào nút submit 'Sign In' đầu tiên do `tabIndex={1}`.
