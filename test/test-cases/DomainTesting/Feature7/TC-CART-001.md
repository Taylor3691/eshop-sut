# TC-CART-001: Hiển thị đầy đủ giỏ hàng có sản phẩm

## Requirement ID
FR-07

## Module / Test type / Technique
Giỏ hàng / Functional UI / Equivalence Partitioning

## Preconditions
- Đang ở trang Giỏ hàng.
- Giỏ có một dòng Sản phẩm A, số lượng 2.

## Test data
| Trạng thái | không trống |
| Sản phẩm | A |
| Số lượng | 2 |

## Test steps
1. Quan sát danh sách.
2. Kiểm tra cột, nút điều chỉnh và nhãn tổng tiền.

## Expected result
Có đủ năm cột bắt buộc, có cả `+`/`-`, nhãn tổng tiền chính xác `Tổng cộng`.
