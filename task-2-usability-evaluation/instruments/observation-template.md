# Mẫu quan sát phiên kiểm thử Usability

## Hướng dẫn ghi chép
- Ghi lại mọi hành động, phản hồi, và khó khăn của người tham gia trong suốt quá trình thực hiện nhiệm vụ.
- Đánh dấu thời gian (giây) kể từ khi bắt đầu nhiệm vụ.
- Ghi chú mức độ nghiêm trọng (1: nhẹ, 2: trung bình, 3: nghiêm trọng) và đưa ra tham chiếu tới bằng chứng (video, ảnh chụp màn hình) khi có.

---

| Thời gian (s) | Hành động của người tham gia | Hành vi quan sát được | Hesitation / Lỗi | Bình luận của người tham gia | Can thiệp của moderator | Mức độ nghiêm trọng (1‑3) | Tham chiếu bằng chứng |
|---|---|---|---|---|---|---|---|
|   |   |   |   |   |   |   |   |
|   |   |   |   |   |   |   |   |
|   |   |   |   |   |   |   |   |

---

**Ghi chú:**
- Đánh dấu “Hesitation” khi người tham gia dừng lại, di chuyển con trỏ mà không thực hiện hành động.
- Đánh dấu “Lỗi” khi người tham gia thực hiện thao tác sai hoặc gặp thông báo lỗi.
- Bằng chứng: video clip trong `evidence/session-recordings/`, ảnh chụp màn hình trong `evidence/screenshots/`.
