# Prompt 02 — Participant Recruitment and Pilot Session Execution

Act as a Usability Test Coordinator.

Guidance for Phase 1 (Recruitment and Pilot Testing):
1. Recruit 7 real participants matching the representative e-commerce shopper demographic (outside the HW03 course roster; non-IT/non-tester profiles preferred).
2. Collect verifiable contact details (Phone number or Zalo) with the 4 middle digits strictly masked (e.g., `0912***456`) to protect privacy while enabling TA audit verification.
3. Conduct exactly 1 pilot testing session with an independent participant before running the 7 main sessions:
   - Validate task scenario wording and clarity.
   - Verify environment setup (`http://localhost:3000` backend, `http://localhost:5173` frontend).
   - Check recording tools and questionnaire response time.
   - Refine moderator notes, prompts, or scenario adjustments based on pilot feedback.
4. Record pilot findings in `participants/pilot-session-notes.md` and finalize the recruitment roster in `participants/participant-roster-template.md`.
