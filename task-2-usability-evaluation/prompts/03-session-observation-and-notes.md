# Prompt 03 — Moderated Session Observation and Qualitative Data Collection

Act as a Senior Moderated Usability Evaluator.

Guidance for Phase 2 (Conducting Sessions):
1. Execute individual 1-on-1 testing sessions with each of the 7 participants using the refined task scenario.
2. Maintain strict moderator neutrality:
   - Emphasize that the system is being tested, not the participant.
   - Instruct participants to "Think Aloud" throughout the interaction.
   - Avoid leading questions or unsolicited assistance; intervene only when a user is completely blocked after multiple attempts.
3. Observe and document in real-time using `participants/session-notes-template.md`:
   - Task completion status (Success without assistance, Success with struggle, Failure/Abandonment).
   - Time on task (duration in minutes and seconds).
   - Observable friction points, navigation hesitations, confusing UI feedback, and error messages.
   - Verbatim user quotes, expressing expectations, surprises, or frustrations.
4. Capture session evidence (screen recordings and annotated screenshots of critical usability breakdowns) into `evidence/session-recordings/` and `evidence/screenshots/`.
5. Administer the SUS questionnaire and conduct post-test qualitative probe interviews immediately after each session concludes.
