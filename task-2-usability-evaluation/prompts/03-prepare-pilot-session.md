# Prompt 03 – Prepare Pilot Session

**Role:** Usability Testing Specialist

**Goal:** Prepare all artefacts needed to run a pilot usability session for the selected end‑to‑end flow:

```
Login → Cart → Apply Coupon → Checkout → Verify Order → Logout
```

**Instructions:**
1. **Read** all planning documents (`planning/*`) and instrument documents (`instruments/*`).
2. **Create** a pilot‑session checklist that will be used before the pilot starts. The checklist must verify:
   - Test environment accessibility.
   - Test account can log in.
   - Shopping cart contains the required products.
   - Coupon test data is available.
   - Checkout can be completed.
   - Order history displays the created order.
   - Logout works correctly.
   - Screen‑recording capability is available.
3. **Prepare** pilot observation documentation that captures any issues discovered during the pilot run. Include sections for:
   - Scenario clarity.
   - Ambiguous wording.
   - Missing prerequisites.
   - Broken or inaccessible functionality.
   - Estimated completion time.
   - Questionnaire clarity.
   - Interview question clarity.
4. **Create** a pilot session record template and an improvement‑log template. Save them to:
   - `participants/pilot/pilot-session-record.md`
   - `participants/pilot/pilot-improvement-log.md`
5. **Important:** The pilot must be conducted with a real person. **Do not** claim that a pilot has already been completed or invent any findings.
6. After the user provides actual pilot observations, you will:
   - Identify problems with the scenario or instruments.
   - Recommend refinements.
   - Update the affected documents.
   - Record all changes in the improvement log.
7. **Commit** all newly created files with the message:
   `docs: prepare usability pilot session`
