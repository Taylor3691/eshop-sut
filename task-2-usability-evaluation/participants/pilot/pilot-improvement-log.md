# Pilot Improvement Log

**Mục đích:** Ghi lại mọi cải tiến, chỉnh sửa và quyết định dựa trên kết quả pilot.

| Ngày | Thay đổi / Vấn đề | Tác động | Hành động / Cập nhật | Người chịu trách nhiệm |
|------|-------------------|----------|----------------------|------------------------|
|      |                   |          |                      |                        |
|      |                   |          |                      |                        |

**Hướng dẫn:**
- Khi người dùng cung cấp phản hồi pilot, điền vào bảng trên.
- Mô tả ngắn gọn vấn đề (ví dụ: "Cụm từ ‘đăng nhập nhanh’ gây nhầm lẫn").
- Đánh giá mức độ ảnh hưởng (Nhẹ/Trung bình/Nặng).
- Ghi rõ hành động sửa (cập nhật kịch bản, sửa mẫu câu hỏi, thêm dữ liệu test,…).
- Ghi tên người chịu trách nhiệm (thường là bạn – *Usability Testing Specialist*).
