# Pilot Session Checklist

> **Mục đích:** Đảm bảo môi trường và dữ liệu chuẩn bị đầy đủ trước khi bắt đầu buổi pilot.

| # | Mục kiểm tra | Trạng thái | Ghi chú |
|---|--------------|------------|--------|
| 1 | Môi trường test (URL, server) có thể truy cập được? | ☐ | |
| 2 | Tài khoản test (email/password) có thể đăng nhập thành công? | ☐ | |
| 3 | Giỏ hàng của tài khoản test chứa các sản phẩm mẫu cần thiết? | ☐ | |
| 4 | Dữ liệu coupon test (mã, điều kiện) đã được thiết lập và khả dụng? | ☐ | |
| 5 | Quy trình checkout có thể hoàn thành (thêm địa chỉ, phương thức thanh toán giả)? | ☐ | |
| 6 | Lịch sử đơn hàng hiển thị đơn vừa tạo với thông tin đầy đủ? | ☐ | |
| 7 | Đăng xuất hoạt động và trả về màn hình đăng nhập? | ☐ | |
| 8 | Công cụ ghi màn hình (OBS, Loom, ... ) đã sẵn sàng và hoạt động? | ☐ | |

**Ghi chú:** Đánh dấu ✅ khi mục đã xác nhận. Nếu có vấn đề, ghi mô tả chi tiết trong mục "Ghi chú".
